How a neural network learns

A neural network is a robot that learns by practicing. Here it decides whether an apple is ripe, using two clues: size and redness.

The idea

Three ideas, one loop

01

Clues go in

The robot looks at size and redness. Each clue enters on the left as one sphere.

02

Helpers listen

Each helper weighs the clues differently and passes its hint to the answer.

03

The answer adds up

The hints combine into one percentage. Above 50% means ripe.

How it gets better

Guess, check, adjust
